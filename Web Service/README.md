# WebService
Esta aplicación, utiliza NodeJS como entorno de desarrollo para acceder y gestionar los datos desde MySQL y servirlos a través de un API REST en formato JSON. Será utilizado más adelante desde una App en Android Studio.

### Requerimientos
- NodeJS
- MySQL
- ThunderClient/Postman

### Base de datos
Restaure la BD, tabla y registros desde el archivo **database.sql**. Antes de continuar verifique que este proceso se realizó correctamente.

### Despliegue
1. Clone el repositorio:
```shell
git clone https://github.com/usuario/mi-proyecto.git
```

2. Restaure node_modules:
```shell
npm install
```

3. Ejecute el servidor local:
```shell
npm run dev
```
